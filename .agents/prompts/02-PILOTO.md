# Prompt — prueba piloto de coordinación (solo lectura)

Usa las reglas y skill de orquestación de EduGrade Flow. Esto es una **prueba técnica sin autorización para escribir**.

1. Verifica que `edugrade-implementer` esté disponible como subagente en tu entorno.
2. Si está disponible, delega una inspección limitada a `src/data/grades.ts` y `docs/07-validaciones.md`: que el implementador identifique DOS reglas documentadas y si existen pruebas que las demuestren. No ejecutar código ni editar archivos.
3. Como ORQUESTADOR, revisa independientemente las afirmaciones del implementador contra los archivos reales; distingue documentación de ejecución.
4. Reporta si la delegación ocurrió realmente, qué herramienta la realizó, qué observaste tú mismo, y qué sigue pendiente.
5. No cambiar estado de archivos, Git, dependencias ni ninguna funcionalidad en este piloto. Si no puedes delegar, reporta la limitación sin simular el resultado.
